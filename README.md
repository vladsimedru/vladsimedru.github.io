# Contact Page

This is a **contact page** web project that features a responsive card design. The card includes personal information, such as name, position, phone number, email, and social media links (LinkedIn). It adapts well to both desktop and mobile devices.

## Table of Contents

- [Features](#features)
- [Technologies Used](#technologies-used)
- [Getting Started](#getting-started)
- [License](#license)

---

## Features

- Responsive design for both desktop and mobile devices.
- Displays:
    - Name
    - Position
    - Phone number
    - Email (with mailto functionality)
    - LinkedIn link (opens in a new tab)
- Clean and professional UI, with hover effects on links for better user interaction.

## Technologies Used

- **HTML5** for the structure.
- **CSS3** for styling and responsiveness.
- **Font Awesome Icons** for adding visually appealing icons to contact details.

## Getting Started

To view the project locally:

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project folder:
   ```bash
   cd <project-folder>
   ```
3. Open the `index.html` file in a browser to see the contact page.
